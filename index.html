我的第一个网站也是 App

这是一个"一个文件两用"的网页：它是网站，也是可以安装到手机/电脑桌面的 App。

技术名字叫 PWA（渐进式网页应用），核心就是"网页 + 一个清单文件 + 一个离线缓存脚本"，全程零费用。

👆 先点一下试试（JavaScript 交互）

点击次数：0

📱 如何把它安装成 App

  • 手机 Chrome / 浏览器：打开页面 → 菜单（⋮）→「添加到主屏幕」/「安装应用」
  • 电脑 Chrome / Edge：地址栏右侧出现⊕图标 → 点击安装
  • 安装后桌面上会出现图标，点开就是独立窗口，还能离线用。
注意：安装 App 功能需要网站跑在 https 或 localhost 上。本地双击打开能看网页、能点按钮，但"安装成 App"要用下面免费的托管方式上线后才行。

🆓 免费托管（上线给别人用）

  • GitHub Pages（推荐）：注册 GitHub 账号 → 新建仓库 → 把这 4 个文件上传 → 仓库 Settings → Pages → 选 main 分支 → 保存，几分钟后就能得到 https 网址。
  • Gitee Pages：国内访问快，需实名认证。
  • Cloudflare Pages：境外访问快，也是免费。

📖 代码怎么看（学习路线）

  • <style> 里的内容是 CSS：控制颜色、字体、排版。
  • <script> 里的内容是 JavaScript：让页面动起来（比如计数）。
  • manifest.json：应用的"身份证"（名字、图标、窗口样式）。
  • sw.js：离线和安装的"服务生"（缓存文件、支持安装）。
